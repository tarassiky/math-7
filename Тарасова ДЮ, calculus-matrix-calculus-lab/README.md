## Данные

Пакет `N = 4` наблюдений, `D = 3` входных координат, `K = 2` выходных:

```
X ∈ R^{4×3}, Y ∈ R^{4×2}
W0 ∈ R^{3×2}, b0 ∈ R^2, λ = 0.05
```

Сквозная функция:

$$
\mathcal L(W, b) = \frac{1}{2N}\|H - Y\|_F^2 + \frac{\lambda}{2}\|W\|_F^2,
\qquad H = \sigma(XW + \mathbf 1_N b^\top).
$$

## Что внутри

- **1.** Суммы, индексы, матричная запись и `einsum`.
- **2.** Производная как предел, правила дифференцирования,
  дифференциал и `max(0, x)`.
- **3.** Частные производные, градиент, полный дифференциал,
  касательная плоскость, численный градиент.
- **4.** Производная по направлению и полная производная.
- **5.** Якобиан, JVP, VJP, цепное правило.
- **6.** Гессиан: минимум, седло, квадратичная модель, HVP.
- **7.** Матричное дифференцирование, `trace`, производная по матрице.
- **8.** Сквозная композиция: `L(W, b)`, `∇_W`, `∇_b`, проверка
  конечными разностями.
- **9.** Градиентный спуск при `η ∈ {0.1, 1, 20}` на 100 шагов.
- **10.** Итоговая карта понятий.
