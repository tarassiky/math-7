# Линейная алгебра для Data Science — лабораторная работа

Численная проверка заданий лабы: векторы, матрицы, линейные отображения,
определитель и ранг, базис, системы уравнений, проекция, МНК, PCA и SVD.

## Запуск

```bash
pip install numpy matplotlib jupyter
jupyter notebook linear_algebra_lab.ipynb
```

В Jupyter: **Kernel → Restart & Run All** — все ячейки должны пройти
без ошибок. Затем **Ctrl+S**, чтобы сохранить выводы и графики.

## Что внутри

- **1. Векторы** — длина, угол, ортогональность, векторы объектов.
- **2. Матрицы** — сложение, линейная комбинация, произведение,
  размерность.
- **3. Линейные отображения** — матрица по правилу, образ вектора.
- **4. Определитель и ранг** — det и rank двух матриц.
- **5. Базис** — проверка базиса, координаты в новом базисе.
- **6. Системы** — квадратная и недоопределённая.
- **7. Проекция** — проекция на прямую с графиком.
- **8. МНК** — коэффициенты, SSE, RMSE, R², графики, проверка
  ортогональности.
- **9. PCA** — стандартизация, ковариация, главная компонента,
  восстановление.
- **10. SVD** — малоранговое приближение, ошибка Фробениуса, связь
  с PCA.
- **11. Итог** — связный текст-карта понятий.
